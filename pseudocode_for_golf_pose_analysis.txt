## 1. Main System Workflow

```
FUNCTION ProcessVideo:

## 3. Golf Pose Analysis Logic

```
FUNCTION CheckGolfPose(image):
    If not enough landmarks detected:
        Return (False, None)

    Initialize list for incorrect body parts

    // Check right arm angle
    Get right shoulder, elbow, and wrist positions
    Calculate right arm angle
    If angle outside acceptable range (60-150 degrees):
        Draw red lines for right arm
        Add "right_arm" to incorrect parts

    // Check left arm angle
    Get left shoulder, elbow, and wrist positions
    Calculate left arm angle
    If angle outside acceptable range (120-175 degrees):
        Draw red lines for left arm
        Add "left_arm" to incorrect parts

    // Check torso rotation
    Get shoulder and hip positions
    Calculate shoulder angle relative to horizontal
    Calculate hip angle relative to horizontal
    Calculate torso rotation (difference between angles)
    If rotation outside acceptable range (20-100 degrees):
        Draw red lines for torso
        Add "torso_rotation" to incorrect parts

    // Check knee bend
    Get hip, knee, and ankle positions for both legs
    Calculate knee angles
    If angles outside acceptable range (150-175 degrees):
        Draw red lines for knees
        Add knee to incorrect parts

    Return (incorrect parts exist, list of incorrect parts)
```

## 4. Swing Phase Detection Logic

```
FUNCTION DetectSwingPhase:
    If not enough landmarks or history:
        Return "Setup"

    Extract key landmarks (wrist, shoulder, hip, head)
    Determine direction golfer is facing

    Check if wrist is above shoulder
    Check if wrist is behind hip
    Calculate arm extension
    Check if club is near impact position
    Check if in follow-through position

    Calculate wrist velocity using landmark history

    // Determine swing phase based on position and velocity
    IF wrist above shoulder AND wrist behind hip:
        Return "Top of Backswing"
    ELSE IF high velocity AND not wrist above shoulder AND not near impact:
        Return "Downswing"
    ELSE IF near impact AND high velocity:
        Return "Impact"
    ELSE IF follow through:
        Return "Follow Through"
    ELSE IF wrist behind hip AND not wrist above shoulder:
        Return "Backswing"
    ELSE IF not wrist behind hip AND not follow through AND not near impact:
        Return "Takeaway"
    ELSE:
        Return "Address"
```

## 5. Angle Calculation Algorithms

### 5.1 Standard Angle Calculation (Vector Method)

```
FUNCTION CalculateAngle(point1, point2, point3):
    // Convert points to numpy arrays
    a = array(point1)
    b = array(point2)
    c = array(point3)

    // Calculate vectors
    ba = a - b  // Vector from point2 to point1
    bc = c - b  // Vector from point2 to point3

    // Calculate angle using dot product
    cosine_angle = dot(ba, bc) / (norm(ba) * norm(bc))
    angle = arccos(clip(cosine_angle, -1.0, 1.0))
    angle_degrees = degrees(angle)

    Return angle_degrees
```

### 5.2 Angle Calculation Using Arctangent (Alternative Method)

```
FUNCTION GetAngle(point1, point2, point3):
    // Extract coordinates
    x1, y1 = point1
    x2, y2 = point2
    x3, y3 = point3

    // Calculate angle using arctangent
    angle = degrees(atan2(y3 - y2, x3 - x2) - atan2(y1 - y2, x1 - x2))

    // Normalize angle to 0-360 range
    If angle < 0:
        angle += 360

    Return angle
```

### 5.3 Alignment Angle Calculation

```
FUNCTION CalculateAlignmentAngle(point1, point2):
    // Calculate angle of line relative to horizontal
    angle = degrees(atan2(point2.y - point1.y, point2.x - point1.x))

    Return angle
```

FUNCTION CombineLandmarks(landmarks1, landmarks2, confidence1, confidence2):
    // Handle cases where one or both sets of landmarks are missing
    IF both landmarks are None:
        Return None
    IF landmarks1 is None:
        Return landmarks2
    IF landmarks2 is None:
        Return landmarks1

    // Combine landmarks based on confidence
    Initialize combined landmarks array
    FOR each landmark index:
        IF confidence1[i] > confidence2[i]:
            Use landmark from camera 1
        ELSE:
            Use landmark from camera 2

    Return combined landmarks

FUNCTION Project3DTo2D(points_3d, rotation_x, rotation_y, rotation_z, scale, center_x, center_y):
    // Convert rotation angles to radians

    Create rotation matrix for X axis
    Create rotation matrix for Y axis
    Create rotation matrix for Z axis

    // Combine rotation matrices
    rotation_matrix = Z matrix × Y matrix × X matrix

    // Apply rotation to all points
    Rotate all 3D points using rotation matrix

    // Project to 2D using orthographic projection
    FOR each rotated point:
        x = point[0] * scale + center_x
        y = point[1] * scale + center_y
        Add (x, y, z) to points_2d list

    Return points_2d
